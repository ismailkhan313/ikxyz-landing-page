# ikxyz-landing-page

The one-page landing site at <https://ismailkhan.xyz> (`index.html` + `style.css`).
GitHub Pages serves this repo's `main` branch; `CNAME` holds the domain, and
`www.ismailkhan.xyz` redirects to it.

`404.html` forwards every other path to the same path on
<https://tech.ismailkhan.xyz>, so links from when the tech wiki lived at the
root (`/wiki/...`, `/log`) keep working.
